# LaserControl 0.1.0 — прототип расширения mBlock 5 для ACMER S1

## Состав

| Файл | Назначение |
|---|---|
| `manifest.json` | Паспорт расширения mBlock 5 (идентификатор, версия, перечень блоков, параметры последовательного порта). |
| `index.js` | Клиентская часть: описание 13 визуальных блоков и отправка JSON-команд через API `device.writeRaw` / `device.writeText`. |
| `firmware/lasercontrol.ino` | Прошивка контроллера-посредника: разбор JSON, проверка границ 130 × 130 мм, генерация G-кода GRBL. |

## Архитектура

```text
mBlock 5 + LaserControl (JSON, USB, 115200)
        ↓
контроллер-посредник (Arduino Mega / ESP32, два UART)
        ↓
ACMER S1 (GRBL, G1 / G28 / M3 / M5 / ! / Ctrl+X)
```

Arduino UNO не используется: у него только один аппаратный UART, а программная эмуляция второго порта снижает надёжность при 115200 бод.

## Установка

1. Установить Arduino IDE и библиотеку ArduinoJson 6.x.
2. Подключить `Serial1` контроллера-посредника к TX/RX гравера, `Serial` — к компьютеру.
3. Загрузить `firmware/lasercontrol.ino` в плату. Не подключать лазер на этапе прошивки.
4. Импортировать `manifest.json` и `index.js` в mBlock 5 Extension Builder (live mode).
5. Выбрать COM-порт платы, скорость 115200 бод.
6. Выполнить проверочную программу: `подключиться → вернуться в ноль → переместить в точку (10; 10) → лазер выключить → вернуться в ноль`.

## Протокол

Команда — одна строка JSON с завершающим `\n`. Пример:

```json
{"cmd":"move","params":{"x":50,"y":50,"abs":true}}
```

Ответ — JSON с полями `status`, `message`, `x`, `y`, `feed`, `laser`.

| cmd | params | Действие GRBL |
|---|---|---|
| `connect` | — | `$I`, ответ `Ready` |
| `home` | — | `G28` |
| `move` | `x`, `y`, `abs` | `G1 X… Y… F…` |
| `laser` | `state` | `M3 S…` / `M5` |
| `power` | `value` (0–100 %) | `M3 S…` (0–255) |
| `feedrate` | `value` (мм/мин) | параметр `F` |
| `delay` | `ms` | задержка в прошивке |
| `line`, `rect`, `circle` | координаты | последовательность `G1` |
| `emergency_stop` | — | `!`, `0x18`, `M5` |
| `status` | — | состояние моста |

## Безопасность

- ACMER S1 — диодный лазер 450–455 нм, класс 4, поле 130 × 130 мм.
- Защитные очки — OD≥4 в диапазоне 445–455 нм. Очки для CO₂-лазера 10,6 мкм не подходят.
- Обязательны кожух/барьер, вытяжка, огнетушитель, аппаратная кнопка останова.
- Перед включением лазера — холостой прогон. Программная проверка границ не отменяет контроль учителя.
- Запрещены ПВХ, винил, поликарбонат и материалы с неизвестным составом.
