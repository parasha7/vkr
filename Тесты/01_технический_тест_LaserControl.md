# Протокол технического теста прототипа «LaserControl»

**Цель:** подтвердить работоспособность связки `mBlock 5 → Arduino-мост → ACMER S1 (GRBL)` и получить доказательства для §2.4 и приложения Г.

**Важно:** ACMER S1 — диодный лазер 450/455 нм, поле **130×130 мм**, класс 4. Все проверки с лучом — только при закрытом кожухе/барьере, в защитных очках **OD≥4 для 445–455 нм**, при работающей вытяжке, с огнетушителем рядом. Запрещены ПВХ, винил, поликарбонат.

## 2. Лог обмена (обязательно приложить)

Скопировать в отдельный файл `данные/serial_log.txt` в формате:

```text
[12:05:01] SENT mBlock->Arduino: {"cmd":"connect"}
[12:05:01] RCVD Arduino->mBlock: {"status":"info","message":"Ready"}
[12:05:03] SENT mBlock->Arduino: {"cmd":"move","params":{"x":50,"y":50,"abs":true}}
[12:05:03] SENT Arduino->GRBL: G1 X50.00 Y50.00 F6000
[12:05:03] RCVD GRBL: ok
[12:05:03] RCVD Arduino->mBlock: {"status":"ok","message":"Move completed"}
```

**Никакие строки не придумываются** — лог снимается реально. Если п. 1.14–1.15 провести нельзя, указать «не проводился».
