# Обработка данных: инструкция и скрипт

## 1. Какие данные нужны

Файл `данные/сырые_данные.csv` с **одной строкой на ученика**. Заполняется учителем по фактическим результатам. Столбцы:

```
code,group,pre_test,motivation_pre,post_test,motivation_post,common_task,extra_task,project_score
S01,ЭГ,,,,,,,,
```

- `pre_test` / `post_test` — баллы из 30;
- `motivation_pre/post` — сумма по 5 пунктам анкеты (5–25);
- `common_task` — обязательная практическая работа из 10 баллов;
- `extra_task` — только ЭГ, 0–10; у КГ оставлять пустым;
- `project_score` — итоговый проект по рубрикатору Д.6 (0–20), если оценивался.

## 2. Что считать

| Показатель | Зачем |
|---|---|
| M ± σ входного теста | Проверка сопоставимости групп |
| Shapiro–Wilk W, p | Проверка нормальности распределения |
| Welch t, df, p | Сравнение итоговых баллов ЭГ и КГ |
| Cohen's d | Величина эффекта (без неё «статистически значимо» мало о чём говорит) |
| 95% CI разности средних | Интервал неопределённости |
| Δ = пост − пре | Прирост в каждой группе |
| Частоты ответов анкеты | Для % использовать **дробь**: 19/22 = 86,4% |

## 3. Скрипт

`analyze.py` читает CSV и печатает готовую таблицу. Запуск:

```bash
python3 -m pip install scipy
python3 analyze.py данные/сырые_данные.csv
```

Если `scipy` недоступен, скрипт всё равно посчитает средние, σ, Welch t и d, но p-value и Шапиро-Уилк будут помечены как «не рассчитано» — значит, в тексте их указывать нельзя.

**Важно:** скрипт не создаёт данные. Если CSV пустой, он выведет сообщение и завершится.

## 4. Как писать в ВКР

Шаблон фразы (заполняется после реального расчёта):

> В ЭГ (n={{N1}}) средний балл итогового теста составил {{M1}} ± {{σ1}}, в КГ (n={{N2}}) — {{M2}} ± {{σ2}}. Различия {{оценка}} (Welch t = {{t}}, df = {{df}}, p = {{p}}, Cohen's d = {{d}}, 95% CI [{{lo}}; {{hi}}]). Прирост относительно входного среза составил {{Δ1}} и {{Δ2}} балла соответственно.

Если тесты не проводились, вместо этого пишем:

> Количественная проверка гипотезы не проводилась; эффективность оценивалась качественно на материалах {{...}}.

## 5. Чего делать нельзя

- Нельзя округлять «до Significant» и писать p<0,001 без фактического расчёта.
- Нельзя сравнивать 7,8 и 5,9 из разных заданий как доказательство эффективности.
- Нельзя указывать проценты без знаменателя (19 из 22 — это 86,4%, а не просто «86%»).
- Нельзя называть пилотный урок «педагогическим экспериментом» с контрольной группой.
