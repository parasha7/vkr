## 2. Входной тест №1 (15 заданий, 30 баллов)

### Часть А — выберите один правильный ответ (задания 1–12, по 2 балла)

1. **Система** — это:
   - а) отдельное техническое устройство;
   - б) совокупность взаимосвязанных элементов, образующих единое целое;
   - в) только компьютерная программа;
   - г) чертёж изделия.

2. **Автоматизированная система** отличается от автоматической тем, что:
   - а) не имеет датчиков;
   - б) часть функций управления выполняет человек, а часть — техническое устройство;
   - в) работает без источников энергии;
   - г) состоит только из механических частей.

3. **Обратная связь** — это:
   - а) передача информации о результате воздействия на объект управления обратно в систему управления;
   - б) соединение двух проводов;
   - в) повторение программы циклически;
   - г) работа без участия оператора.

4. **Исполнительный механизм** в системе «автоматический полив растений» — это:
   - а) датчик влажности почвы;
   - б) микроконтроллер;
   - в) насос, подающий воду;
   - г) сам ученик.

5. **Датчик** в автоматизированной системе предназначен для:
   - а) измерения параметра и передачи сигнала в контроллер;
   - б) непосредственного выполнения рабочего движения;
   - в) хранения программы;
   - г) питания исполнителя.

6. **Алгоритм** — это:
   - а) график выполнения работ;
   - б) конечная последовательность действий для решения задачи;
   - в) схема электрической цепи;
   - г) язык программирования.

7. Какая алгоритмическая конструкция используется для многократного повторения действий?
   - а) следование;
   - б) ветвление;
   - в) цикл;
   - г) подпрограмма.

8. Блок mBlock `если … то … иначе` реализует:
   - а) ветвление;
   - б) цикл;
   - в) линейная последовательность;
   - г) остановку программы.

9. Что делает блок «установить цифровой пин 13 в значение высокий»?
   - а) считывает уровень с пина 13;
   - б) подаёт на пин 13 напряжение высокого уровня;
   - в) отключает плату Arduino;
   - г) меняет скорость гравировки.

10. Рабочее поле лазерного гравера ACMER S1 имеет размер:
    - а) 400×300 мм;
    - б) 130×130 мм;
    - в) 1000×1000 мм;
    - г) 50×50 мм.

11. **G-код** — это:
    - а) формат растрового изображения;
    - б) язык команд для станков с ЧПУ;
    - в) название графического редактора;
    - г) тип лазерного луча.

12. Какие защитные очки нужны для работы с ACMER S1?
    - а) любые строительные;
    - б) для CO₂-лазера 10,6 мкм;
    - в) с оптической плотностью OD≥4 в диапазоне 445–455 нм;
    - г) обычные прозрачные очки.

### Часть Б — короткий ответ с пояснением (задания 13–15, по 2 балла: 1 за ответ + 1 за объяснение)

13. Верно ли утверждение: «Гравер с обратной связью обязательно имеет датчик положения головки»? Ответ: _______. Пояснение: __________________________.

14. Верно ли, что команда `M5` в GRBL включает лазер на полную мощность? Ответ: _______. Пояснение: __________________________.

15. Можно ли гравировать ПВХ (винил) на школьном лазерном гравере? Ответ: _______. Пояснение: __________________________.
