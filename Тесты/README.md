# Комплект тестов и протоколов для апробации УМК

**Назначение.** Здесь собраны все инструменты, которые нужны, чтобы получить **реальные** данные для главы 3 ВКР. Ни один результат не должен вноситься в работу до фактического проведения теста.

**Правило:** если тест не проведён — в ВКР пишем «не проводился» или «планируется». Выдуманные протоколы, ведомости, подписи и фотографии не создаются.

## Состав папки

| Файл | Что делать | Кто заполняет |
|---|---|---|
| `00_паспорт_эксперимента.md` | Заполнить реквизиты: школа, классы, даты, состав групп, оборудование | Вы |
| `01_технический_тест_LaserControl.md` | Прогнать 17 технических проверок прототипа с реальным ACMER S1 | Вы / разработчик прототипа |
| `02_констатирующий_этап.md` | Провести входной тест и анкету до начала модуля | Учитель |
| `03_формирующий_этап.md` | Вести дневник наблюдений на занятиях | Учитель |
| `04_контрольный_этап.md` | Итоговый тест, сопоставимая практическая работа, анкета рефлексии | Учитель |
| `05_обработка_данных.md` | Инструкция по расчёту статистики + готовый скрипт | Я (после получения данных) |
| `данные/` | Пустые CSV-шаблоны — только заголовки, без чисел | Вы заполняете |

## Что прислать мне после проведения тестов

1. Заполненные Markdown/Google-таблицы или просто скопированные строки из `данные/*.csv`.
2. Лог последовательного порта (`*.txt`) из раздела 1.7 технического теста.
3. Фотографии: общий вид стенда, экран mBlock с расширением, образцы гравировки, момент занятия **без лиц учащихся** (или с согласия).
4. Скани/фото подписей в журнале инструктажа и акта внедрения (если есть).

Я затем: пересчитаю статистику, заполню главу 3, таблицы и рисунки, обновлю Введение и Заключение под реальные формулировки.

## Анонимизация

В открытых данных ВКР используются только коды `S01…S46`, `T01…` — без фамилий. ФИО хранятся только у вас в школе. Если согласия на использование изображений нет — фото в работу не идут.

## Минимум, который делает работу защищаемой

- Технический тест прототипа (**обязательно**: он подтверждает, что расширение работает).
- Хотя бы один реально проведённый урок/мастер-класс с дневником наблюдений (**минимум для слова «апробация»**).
- Входной и итоговый срезы в ЭГ и КГ, если классы доступны (**если нет — глава 3 переименовывается в качественную апробацию, без t-критерия**).
